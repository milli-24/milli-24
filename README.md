### 🧠 Currently
Summer research @ **NGNI Lab, Imperial College London** — electrode-tissue interface characterisation for HD-EMG wearables.

### 🚀 Featured project — [BCI Arm Control](https://github.com/milli-24/bci-arm-control)
A closed-loop hybrid EMG/EEG brain–computer interface for prosthetic hand control, built on consumer-grade OpenBCI Cyton hardware (~£1,000). My BEng final-year dissertation.

- **95.9 %** three-class EMG gesture accuracy
- **71.1 %** EEG motor imagery on the 10-subject PhysioNet benchmark
- **35–45 ms** end-to-end EMG control latency
- Real-time pipeline in Python + MuJoCo simulation

### 🔬 What I work on
- Closed-loop hybrid EEG–EMG Brain–Computer Interfaces for prosthetic control
- Neural signal processing and machine learning for motor-intention decoding
- Electrode design and bioelectronics — 3D-printed conductive polymer probes, impedance spectroscopy
